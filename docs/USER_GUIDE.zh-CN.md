# gbi 用户指南

本指南面向业务用户与管理员,介绍 gbi 的日常使用。安装与运维请阅读[部署指南](DEPLOYMENT.zh-CN.md);项目概况见 [../README.zh-CN.md](../README.zh-CN.md)。

> English: [USER_GUIDE.md](USER_GUIDE.md) · English README: [../README.md](../README.md)

---

## 1. 角色与登录

| 角色 | 能力 |
|------|------|
| **admin(管理员)** | 全部功能:用户/部门/用户组/角色、数据主题、BI 页面、导航菜单、大模型设置、品牌设置 |
| **developer(开发者)** | 数据主题管理、BI 页面管理、导航菜单管理、AI 工作台;可访问门户 |
| **user(普通用户)** | 登录后进入 BI 门户,查看被授权(ACL)的已发布页面 |

登录:浏览器访问部署地址(默认 `http://localhost:8080`),输入用户名与密码。系统初始化管理员为 **admin / admin123**,请首次登录后在「用户管理」中重置密码。

> 密码遗忘:由管理员在「用户管理 → 重置密码」处理;请确保至少保留一个可用的管理员账号。

## 2. 五分钟上手

1. **配置大模型**(管理员):控制台 →「大模型设置」→ 编辑默认 Provider、填写 API Key、确认模型名 → 保存。
2. **建数据主题**:控制台 →「数据主题管理」→ 新建,填写名称与编码(编码须以小写字母开头,仅小写字母/数字/下划线,≤32 字符)。
3. **导入数据**:选中主题 →「导入Excel」→ 选择文件与模式(Create 建新表 / Append 追加到已有表)。
4. **建 BI 页面**:「BI页面管理」→ 新建页面 → 在行内点击「进入工作台」。
5. **让 AI 生成图表**:在工作台勾选本次分析要用的数据主题 → 用自然语言描述需求 → 发送。模型会查看表结构、试跑 SQL 并生成图表。
6. **发布并配置门户**:回到页面列表 →「发布」→「权限」授权用户/用户组 →「导航菜单管理」把页面挂到菜单。
7. **查看门户**:访问 `/portal`(或「进入BI门户」),按菜单浏览已授权页面。

## 3. 管理控制台

### 3.1 用户、部门、用户组、角色

- **用户管理**:新建用户(用户名、密码、姓名、部门、角色)、编辑、重置密码、删除;
- **部门管理**:部门树维护;
- **用户组管理**:组的成员维护;页面 ACL 支持按"用户组"授权;
- **角色管理**:内置 admin/developer/user,可重命名(能力由系统策略决定)。

### 3.2 数据主题管理

数据主题是一组相关数据表的容器,每个主题对应一个独立的 SQLite 库文件。

- 新建主题:名称 + 编码(编码创建后用于 SQL 中的库前缀,请谨慎设置);
- 主题下可包含多张表,顶部以页签切换;
- **新建表**:指定表类型与列定义。
  - **DWD**(明细数据):物理表名自动加前缀,如基础名 `orders` → `dwd_orders`;
  - **DIM**(维度数据):`dim_<基础名>`;
- **导入 Excel**(单次上限 2GB):
  - `导入并建新表`:读取首个工作表,首行为列名,自动推断每列类型(TEXT/INTEGER/REAL/DATE);
  - `导入已有表`:按列名匹配已有表并追加行;列名需与目标表一致;
  - 建议:首行表头唯一且非空;纯数字列保持数值格式;空单元格导入为 NULL;
- **删除表**:会删除该表的全部数据,操作前请确认(有二次确认弹窗)。

### 3.3 表详情(数据浏览)

选中主题后,点击表页签即可浏览数据:

- **编辑单元格**:直接在单元格输入修改,失焦/回车保存;数值列会校验类型;
- **删除行**:行尾「删除」并确认;
- **列筛选**(服务端):点击表头漏斗图标,勾选该列的一个或多个取值后「确定」;筛选即时生效,「清除筛选」恢复;每列候选值最多展示 100 个不同值;
- **列设置**:勾选需要显示的列,支持「全选/全不选」;设置按浏览器本地记忆;
- **分页**:页大小可选 10/20/50/100;
- **宽表浏览**:表格内部横向滚动,「#」与「操作」列固定显示;列名过长可悬浮查看完整名称、类型与注释。

### 3.4 BI 页面管理

- **新建页面**:填写名称与描述,新页面为草稿状态;
- **进入工作台**:行内按钮,打开该页面的 AI 工作台(见第 4 节);
- **发布 / 取消发布**:只有已发布且被 ACL 授权的页面会出现在门户;
- **权限(ACL)**:按**用户**或**用户组**授权页面可见性;
- **版本**:查看历史版本并恢复(每次更新页面配置会生成版本);
- **删除**:删除页面与其版本记录。

### 3.5 导航菜单管理

门户的顶部导航由「菜单 + 菜单项」构成:

1. 新建**菜单**(如「销售分析」);
2. 在菜单下新增**菜单项**,为每项选择要展示的 BI 页面;
3. 门户按菜单显示为顶部切换页,菜单项对应当前菜单下的页面列表。

用户看不到无权访问的菜单/页面。

### 3.6 大模型设置(仅管理员)

管理 AI 工作台使用的模型:

- **Provider**:名称、Base URL(**必须是 Anthropic 兼容端点**,例如 `https://api.deepseek.com/anthropic`)、API Key(保存后只显示掩码,编辑时留空表示不修改);
- **Model**:模型名、上下文窗口(默认 384000)、最大输出(默认 16384);
  - 约束:**最大输出必须大于 8192**(系统思考预算)且**小于上下文窗口**;
- **设为当前**:全局唯一的「当前模型」,切换后下一次对话立即生效,无需重启;
- 初始化会播种 `deepseek` Provider 与 `deepseek-flash` 模型,但 **API Key 为空**,需要你填写;若你的端点不提供该模型名,请改成实际模型名;
- 删除保护:不能直接删除当前模型;有模型的 Provider 需先删除其模型。

### 3.7 品牌设置(仅管理员)

- 修改**系统名称**与**浏览器标题**(全站生效,含登录页);
- 上传 **Logo** 与 **Favicon**:仅支持 **PNG / ICO**,单个文件 ≤ **512KB**,支持预览;
- 可单独恢复某张图片,或「恢复全部默认」(名称回到「生成式 BI」,图片回到内置 favicon);
- 上传后全站立即生效(浏览器标签页图标会使用带版本号的地址,无需清缓存)。

## 4. AI 工作台(Studio)

入口:「BI页面管理」行内「进入工作台」,或直接访问 `/studio?page=<页面ID>`。

使用流程:

1. 在顶部选择一个或多个**数据主题**(AI 只能访问你勾选的主题数据);
2. 输入需求(例如:"按省份统计月度销量,柱状图 + 折线趋势"),发送;
3. 助手会依次:查看表结构与样例数据 → 编写并**试跑只读 SQL** → 更新页面图表配置 → 自动**核验渲染**;若前端报告图表渲染错误,会把错误回灌给模型继续修正;
4. 右侧实时预览页面;满意后回到页面列表发布。

说明与限制:

- 查询仅允许单条 `SELECT`/`WITH`,自动限制最多 10000 行;回填给模型的结果最多 200 行(超出会提示总计行数);
- 对话按页面保存,刷新后仍可继续;「新对话」只清空聊天记录,**不会**影响已生成的页面配置;
- 若模型声称完成但图表空白,可发送"检查页面渲染错误"让它自查;
- 模型不可用/报错时,先检查「大模型设置」的当前模型与 API Key。

## 5. BI 门户

- 访问 `/portal`(登录后);
- 顶部菜单对应「导航菜单管理」中的菜单,菜单项对应页面;
- 仅展示**已发布**且**对当前用户/用户组授权**的页面;
- 可通过链接直接打开指定页面(如 `/portal?page=<页面ID>`,需有权限);
- 门户中的图表与页面在工作台中看到的配置一致;管理员/开发者可从门户跳到控制台。

## 6. 常见问题

| 问题 | 处理 |
|------|------|
| AI 不回复或报错 | 检查「大模型设置」:是否有当前模型、API Key 是否已配置、Base URL 是否为 Anthropic 兼容端点;最大输出需 >8192 且 <上下文窗口 |
| 图表空白或显示异常 | 在工作台发送"检查页面渲染错误";常见原因是图表 `encode` 字段与 SQL 返回列名不一致,让 AI 修正即可 |
| Excel 导入失败 | 检查首行表头是否为空/重复;Append 模式下列名是否与目标表一致;文件是否超过 2GB 或代理的上传上限 |
| 列筛选没有选项 | 该列没有有效数据(全为 NULL/空串),或候选值超过 100 个仅显示前 100 个 |
| 看不到某个页面 | 页面是否已发布、是否在页面「权限」中授权给你或你的用户组、菜单是否包含该页面 |
| 登录后提示 401/403 | 登录状态过期或被禁用账号;重新登录;仍失败请联系管理员 |
| 修改品牌/模型后未生效 | 品牌与当前模型切换均即时生效;若页面停留过久可刷新;模型切换从下一条对话开始使用 |
| 误删了表/行 | 表删除不可恢复;行/单元格删除无法撤销。重要数据请按部署指南定期备份 |

更多运维问题(端口、反向代理、升级、备份)见[部署指南](DEPLOYMENT.zh-CN.md)。
